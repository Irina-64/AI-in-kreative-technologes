# Журнал выполнения ЛР 8 в Engee (19–20.09.2026)

**Почему Engee.** Бесплатные ресурсы Google Colab у проверявшего закончились; исполняемая платформа ЛР 8 перенесена в Engee. Первоначальная проверка выполнена в Google Colab (Tesla T4) и сохранена как сопоставление (`results_30_variants_colab.json`, раздел «Сопоставление» ниже).

**Среда.** Engee 26.8.2-H3; Julia 1.12.4 (5 потоков, 16 ГБ ОЗУ), Python 3.11 из `/user/.user_venvs/py3.11`, PyTorch 2.4.1+cu121, `torch.cuda.is_available()` = `False` (графического ускорителя нет). Есть доступ в интернет (PyPI, Hugging Face, GitHub отвечали кодом 200). В окружении также TensorFlow, Keras, NumPy, scikit-learn, Pillow; есть ядро Jupyter `engee_py`.

**Версии библиотеки.** Первая проверка в Colab выполнена на `lab08_lib.py` с SHA-256 `DE82B793…` (8427 байт); итоговый файл для Engee (`F414C49B…`, 8682 байта) отличается от него только комментарием в шапке и одной строкой `torch.set_num_threads(min(4, torch.get_num_threads()))`. Все числа МУ и лекции получены на итоговом файле в Engee.

**Ход проверки.**

1. Файлы `lab07_lib.py` (8679 байт, SHA-256 `D84B83A8…`), `lab08_lib.py` (8682 байта, `F414C49B…`), `lab08_demo.py` (3067 байт, `8AB781BF…`), `run_lr08.py` (`06096918…` — первая версия, позже заменена возобновляемой) загружены в `/user/`; SHA-256 на сервере сверены. Позже все файлы курса собраны в `/user/ii-in-kt/`.
2. Ввод длинного кода в командную строку Engee не работает (ввод по символам упирается в тайм-аут); загрузка файлов — штатной загрузкой (`file_upload` из папки сеанса).
3. Быстродействие. По умолчанию PyTorch видит 112 потоков при пяти доступных ядрах: 50 умножений матриц 1024×1024 — 6,96 с. Одна эпоха обучения автокодировщика ЛР 7 (4096 сцен): 2,58 с (1 поток), 1,07 с (4 потока), 1,85 с (8 потоков). Поэтому в `lab08_lib.py` добавлено `torch.set_num_threads(min(4, …))`. Одно обучение автокодировщика ЛР 7 (20 эпох, 1 поток): 47 с, PSNR 25,87 дБ (в Colab ≈26,0 дБ), разрыв «обучение − тест» 0,043 дБ.
4. Полный прогон 30 вариантов: пять фоновых процессов `run_lr08.py <набор>` по одному потоку. Набор 0 (варианты 1–6) выполнен за 1624 с (27 мин; первый вариант 625 с, так как обучаются модели для всех режимов, остальные быстрее за счёт кэша). Наборы 1–4 выполнены аналогично; после перезапусков ядра консоли процессы наборов 2–4 запускались заново по одному; запускатель `run_lr08.py` сделан возобновляемым (пропускает готовые варианты), чтобы повторный запуск не пересчитывал готовое. Итог: во всех пяти файлах `res_c0…4.jsonl` по 6 строк, значений NaN нет. Сводка — `results_30_variants.json`.
5. Особенность консоли Engee: запуск фонового процесса из Julia (`run(pipeline(…), wait=false)`) зависит от `stdin=devnull`; после запуска консоль иногда перестаёт отвечать до перезапуска ядра; попытка запуска через `sh` с `nohup` процессов не создала.
6. Демонстрационный код `lab08_demo.py` выполнен (второй запуск; первый запуск, `demo_out.txt`, остановился после блока диагностики без сообщения об ошибке, причина не установлена). Результаты: таблица четырёх показателей варианта 1, диагностика по трём моделям, схлопывание без разогрева и с разогревом, лист `comparison.png` (открыт в Engee и снят с экрана двумя фрагментами, склеенными по перекрытию; в папке `demo_journal` он сохранён в уменьшенном виде).
