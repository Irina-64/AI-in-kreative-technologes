**Ход проверки.**

4. Исправления: разогрев KL (`warmup=10`) и гребневое решение для $R^2$ (`solve` с добавкой $10^{-6}$ в двойной точности). Итоговая версия `lab08_lib.py`: 8427 байт, SHA-256 `DE82B793…CF9A`; в блокноте изменения применены заменой текста и сверены по SHA-256 с локальным файлом.
5. Полный прогон 30 вариантов на итоговой версии: 454 с (7 мин 34 с), исключений и NaN нет. Результаты — `results_30_variants.json` (среднее, разброс по seed, режим A и B по четырём показателям).
