# Журнал замера SD Turbo в среде Engee (20.09.2026)

**Цель.** Проверить, можно ли выполнять ЛР 9–10 (генерация изображений моделью SD Turbo) в Engee на процессоре, и получить измеренное время для лекции 6.

**Среда.** Engee 26.8.2-H3; Python 3.11 (venv `/user/.user_venvs/py3.11`); torch 2.4.1+cu121, GPU нет; 4 потока (`torch.set_num_threads(4)`); тип вычислений float32. Диск: доступно 6,2 ТБ на томе `/user`; оперативная память узла 251 ГБ всего, свободно около 220 ГБ (значения узла, а не квота сеанса; пиковый расход процесса замера см. ниже).

**Модель.** `stabilityai/sd-turbo`, ревизия `b261bac6fd2cf515557d5d0707481eafa0485ec2`; запрос «a photo of a red cup on a wooden table, soft daylight»; `guidance_scale` = 0,0; генератор CPU, seed 101. Скрипт: `sdturbo_bench.py` (в этой папке и в `/user/ii-in-kt/`); результаты — `bench_4.jsonl`, вывод ошибок — `bench_err.txt`.

## Установка пакетов (три попытки)

| Попытка | Версии | Итог |
|---|---|---|
| 1 | diffusers 0.40.0, transformers 5.17.0, huggingface-hub 1.32.0 | не работает: `transformers` пишет «PyTorch >= 2.5 is required but found 2.4.1», текстовый кодировщик не загружается |
| 2 | diffusers 0.39.0, transformers 4.57.6, huggingface-hub 0.36.2 | не работает: `ValueError: infer_schema(func): Parameter q has unsupported type torch.Tensor` при импорте `diffusers` (регистрация собственных операторов не совместима с torch 2.4.1) |
| 3 | **diffusers 0.32.2, transformers 4.57.6, huggingface-hub 0.36.2** | работает; torch не менялся (2.4.1+cu121) |

Вывод для МУ: в Engee использовать `pip install "diffusers==0.32.2" "transformers<5"` (без обновления torch), иначе импорт падает.

## Измерения (4 потока, float32, 1 шаг, если не указано иное)

Загрузка модели (первый запуск, включая скачивание весов): **64,1 с**. Пиковая память процесса (`ru_maxrss`): **7144 МБ** (после загрузки — 5117 МБ).

| Размер, пикселей | Шагов | Повтор 0, с | Повтор 1, с |
|---|---:|---:|---:|
| 256×256 | 1 | 13,8 (первый вызов, прогрев) | 4,8 |
| 384×384 | 1 | 9,6 | 9,8 |
| 512×512 | 1 | 17,3 | 18,0 |
| 512×512 | 2 | 22,4 | 22,8 |
| 512×512 | 4 | 34,2 | 34,2 |

По трём точкам (1, 2, 4 шага, повтор 1) время при 512×512 описывается прямой около 12,6 + 5,4·(число шагов) секунд: постоянная часть (кодировщик текста и декодер VAE) заметно больше одного шага сети шумоподавления. Для сравнения: в Colab на T4 (ЛР 6, лекция 4) один шаг при 512×512 занимал 0,34 с, то есть Engee медленнее примерно в 50 раз (18,0 / 0,34 ≈ 53). Время при 1 шаге растёт почти пропорционально площади кадра: 4,8; 9,8 и 18,0 с при 0,066; 0,147 и 0,262 млн пикселей, то есть 73, 66 и 69 с на мегапиксель.

**Оценка для ЛР 9–10.** Один вариант ЛР с 10 изображениями (5 seed × 2 условия) при 512×512 и 1 шаге занимает около 3 минут; 30 вариантов — около 90 минут одним процессом или около 45 минут двумя процессами по 2 потока (не проверялось).

## Оговорки

* Замер выполнен один раз; повторы внутри серии различаются не более чем на 0,7 с (кроме прогрева).
* Число потоков и нагрузка на общий узел могут менять время; числа приведены как ориентир для сеанса 20.09.2026.
