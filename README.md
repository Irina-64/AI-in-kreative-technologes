# AI-in-kreative-technologes

Материалы курса «Искусственный интеллект в креативных технологиях» для магистров первого года обучения (09.04.02 «Информационные системы и технологии», ДГТУ).

В репозиторий вынесены **воспроизводимые артефакты** лабораторных работ: библиотеки и скрипты (`src/`), таблицы 30 индивидуальных вариантов (`variants_lr*.json`) и журналы выполнения с результатами (`demo_journal/`). Методические указания, конспекты лекций и презентации в репозиторий не входят (в них есть материалы преподавателя: ключи, результаты по вариантам).

## Структура

```
labs/<ЛР…>/src/               код лабораторной работы (Python или Julia)
labs/<ЛР…>/variants_lr*.json  30 вариантов: набор данных или контекст × изменяемый фактор, критерий, риск
labs/<ЛР…>/demo_journal/      журнал выполнения демонстрационного варианта, сводки результатов, небольшие рисунки
lectures/<Лекция…>/           скрипты и журналы измерений, на которые ссылаются конспекты
```

## Среда воспроизведения

- **Engee** 26.8.2-H3, процессор, Python 3.11 (`/user/.user_venvs/py3.11`), PyTorch 2.4.1+cu121; `diffusers==0.32.2`, `transformers<5` (новые версии несовместимы с PyTorch 2.4.1). Ограничение числа потоков — `torch.set_num_threads(4)` (по умолчанию PyTorch видит 112 потоков при 5 ядрах).
- **Google Colab** (ЛР 5–8), GPU T4: результаты помечены в журналах; значения между платформами совпадают качественно, но не побитово.
- Числа в журналах получены реальными запусками; расчёты на процессоре не воспроизводятся побитово (различия порядка долей разброса между seed).

## Как проверить воспроизведение

1. Скопируйте папку работы в Engee (`/user/ii-in-kt/…`) или в Colab; установите зависимости из шапки `src/*_lib.py`.
2. Запустите демонстрационный скрипт (`*_demo.py`) или вариант `variant_summary(n)`; сравните с `demo_journal/results_*` в пределах разброса между seed.
3. Расхождения записывайте в журнал по образцу `demo_journal/engee_run_log.md`.

## Примечания

- В `demo_journal` не сохранены рисунки размером более 400 КБ (ЛР 10: листы сравнения изображений остаются в исходной папке автора).
- Дубликаты вида `lab07_lib(1).py` (следствие загрузки в среду) не выгружались.
